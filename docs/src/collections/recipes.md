# Task recipes

Start here when you know the result you want. A recipe takes a defined input
through a focused procedure to a recognizable result, with the necessary
conditions and explanations beside the code. You can enter at the task you
need; the mathematical lessons and library guides supply context when useful.

For setup, [install TamerOp and open a notebook](../start/install.md).
Installation is also always available at the top of the sidebar.
