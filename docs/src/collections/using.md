# Using TamerOp

Start with the object or question you have. These guides explain how to choose
and combine TamerOp's capabilities, understand the returned objects, and
explore useful variations. If you already know the task you want to complete,
the [task recipes](recipes.md) provide focused procedures with defined results.

For a first session, [install and open a notebook](../start/install.md).
If you already have an encoding, [explore its spaces and maps](../../spaces_and_maps.md)
to connect parameter queries, finite labels, matrices and figures. If your
question concerns one changing parameter, the
[ordinary-persistence guide](../../ordinary_persistence.md) starts directly
from a filtered input and its barcode.
