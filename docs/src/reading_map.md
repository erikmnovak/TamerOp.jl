# Choose a reading path

Choose a starting point: **an example** you can see, or **the definitions**
of spaces and maps. Both routes meet at **finite encodings**. From “Why two
parameters?”, you can continue directly or explore the full definitions first.

Installation is only needed to run the notebook; you can read its saved
figures without it. Arrows suggest continuations, not prerequisites.

After finite encodings, inspect the square in code or learn how regions and
a matrix describe it. Either route leads to the question of when finite
descriptions exist.

Lesson cards open pages on this site, including the ring and square inspection
notebooks. On a narrow screen, scroll sideways or use the linked outline below
the map.
